使用 Claude Code 連接本地模型

2026-08-25

讓 Claude Code 透過 settings.json 改指向本機 LM Studio 啟動的 OpenAI-compatible API，改用本地跑的模型 (如 Qwen)，不再打 Anthropic 官方 API。

Version

Claude Code 2.1.231
Qwen 3.8-27b

Claude Code

settings.json

{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:1234",
    "ANTHROPIC_AUTH_TOKEN": "lmstudio",
    "CLAUDE_CODE_ATTRIBUTION_HEADER": "0",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "qwen/qwen3.8-27b",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "qwen/qwen3.8-27b",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "qwen/qwen3.8-27b"
  },
}
  • 位於 .claude/settings.json
  • ANTHROPIC_BASE_URL：改指向本機 LM Studio 開的 OpenAI-compatible server (預設 http://127.0.0.1:1234)，Claude Code 就不會再打 Anthropic 官方 API
  • ANTHROPIC_AUTH_TOKEN：LM Studio 本地端不驗證 token，隨便填一個字串即可（如 lmstudio），只要非空值讓 Claude Code 通過檢查就好
  • CLAUDE_CODE_ATTRIBUTION_HEADER：設為 "0" 關閉 Claude Code 預設附加的 attribution header，避免 LM Studio 的 API 不認得這個 header 而回錯誤
  • ANTHROPIC_DEFAULT_SONNET_MODEL：Claude Code 呼叫 Sonnet 等級模型時，實際要用的本地模型名稱，需與 LM Studio 中載入的模型 ID 一致（qwen/qwen3.8-27b）
  • ANTHROPIC_DEFAULT_HAIKU_MODEL：Claude Code 呼叫 Haiku 等級（小型/快速任務）模型時，實際要用的本地模型名稱，這裡同樣導到 qwen/qwen3.8-27b
  • ANTHROPIC_DEFAULT_OPUS_MODEL：Claude Code 呼叫 Opus 等級模型時，實際要用的本地模型名稱，這裡同樣導到 qwen/qwen3.8-27b

Conclusion

  • Claude for Mac (桌面版) 無法連接本地模型，只有 Claude Code 能透過 settings.json 改 ANTHROPIC_BASE_URL 導向本地端
  • 三個 ANTHROPIC_DEFAULT_*_MODEL 全部指向同一顆本地模型，是因為 LM Studio 本機只跑了一顆 qwen/qwen3.8-27b，若日後同時載入多顆模型，可依任務等級分別指定不同模型名稱
